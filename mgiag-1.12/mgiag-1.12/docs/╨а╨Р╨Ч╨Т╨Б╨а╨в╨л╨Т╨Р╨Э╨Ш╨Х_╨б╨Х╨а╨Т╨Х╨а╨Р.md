# Сервер «ХАОС» — запуск и обновление

Сервер — отдельная программа (Node.js 18+), папка `server/`. GitHub Pages умеет отдавать только
файлы, поэтому аккаунты, друзья и комнаты работают **только** при запущенном сервере.
Игра (папка с `index.html`) и сервер обновляются независимо.

## 1. Проверка на своём компьютере (5 минут)
```
cd server
npm install
npm start            # слушает порт 8080
```
В `server-config.js` (рядом с `index.html`) впиши `window.MGIAG_SERVER = 'ws://localhost:8080';`
и открой игру через любой локальный веб-сервер (например `npx serve .` в корне проекта).
Автотест сервера: `npm test` (77 проверок, поднимает сервер сам).

## 2. Публичный сервер
Нужен хостинг с постоянным процессом и **постоянным диском** (иначе аккаунты пропадут при перезапуске):
- **VPS** (любой, ~3–5 $/мес) — самый надёжный. `git clone`, `cd server && npm install`,
  запуск через `pm2 start server.js` или systemd. HTTPS даёт Caddy/nginx (`wss://` обязателен,
  потому что игра на https://github.io).
- **Fly.io / Railway** — создай приложение из папки `server/`, подключи **Volume** и укажи
  переменную `DATA_DIR` = путь к тому (например `/data`).
- **Render (бесплатный план)** — диск стирается при каждом перезапуске: подходит только для проверки,
  для настоящей игры нужен платный Disk.

Переменные окружения (все необязательны):
| Переменная | Значение |
|---|---|
| `PORT` | порт (хостинг обычно задаёт сам) |
| `DATA_DIR` | где лежит `db.json` (аккаунты). **Должна быть на постоянном диске** |
| `ALLOWED_ORIGINS` | кто может подключаться, например `https://ТВОЙ-НИК.github.io` (по умолчанию все) |
| `TRUST_PROXY` | `1`, если сервер за nginx/Caddy/Cloudflare (чтобы видеть настоящий IP) |
| `ROOM_MAX` | размер комнаты (по умолчанию 25) |

Проверка: открой `https://адрес-сервера/health` — должно быть `{"ok":true,...}`.
Потом впиши `wss://адрес-сервера` в `server-config.js` и загрузи файл на GitHub.

## 3. Резервные копии
Все аккаунты — один файл `DATA_DIR/db.json` (+ `db.json.bak`). Копируй его раз в день.
Сервер пишет файл атомарно и **никогда не затирает повреждённую базу**: он останавливается и сохраняет копию `.corrupt-…`.

## 4. Как обновлять сервер
Загрузи новую папку `server/` на хостинг **без** папки `data/` и перезапусти процесс. Аккаунты лежат в `DATA_DIR`
и не затрагиваются.

## 5. Безопасность
- Пароли: scrypt + соль, в базе нет паролей в открытом виде (проверено тестом).
- Сессии: токен хранится на сервере только как SHA-256.
- Защита от подбора: блокировка ника после 5 ошибок, лимит неудачных попыток и регистраций с одного IP.
- Урон считает сервер (оружие, дальность, перезарядка). Позиции игроков сервер **принимает от клиента**,
  поэтому от телепорт-читов полной защиты нет — это дружеская игра, а не турнирный шутер.
